# 射出成形プロセスウィンドウ（応答曲面法）

任意の入力因子と出力応答の関係を二次応答曲面でモデル化するStreamlitアプリです。初期設定は射出速度・保圧圧力・金型温度と、ヒケ深さ・反り量・光沢度です。各品質規格を同時に満たすプロセスウィンドウも可視化します。

## 起動

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

ブラウザが開いたら、左側で項目を設定してCSVを読み込みます。初期設定でCSV未選択時はBox–Behnken計画（中心点1回）の13点デモデータで動作します。画面の「入力テンプレートをダウンロード」から現在の項目構成に合う書式例を取得できます。

## 入出力項目とCSV列

サイドバーで入力因子数（2～6）と出力応答数（1～6）、それぞれの項目名を設定できます。CSVには、そこで指定したすべての列が必要です。単位は任意ですが、すべての行で統一してください。

初期設定は次の6列です。

```text
射出速度,保圧圧力,金型温度,ヒケ深さ,反り量,光沢度
```

- 必要な最小実験数は因子数 `k` に応じて `(k+1)(k+2)/2` 点です。誤差評価のため、最小数より多い実験を推奨します。
- 各因子の一次項・二次項と、すべての2因子交互作用を含む完全二次モデルです。
- 実験範囲外には外挿しません。
- LOOCV R²とRMSEで未知条件への予測性能を確認してください。
- 推奨条件は必ず実機の確認実験で検証してください。

## 解析内容

- Box–Behnken計画／中心複合計画（面中心型・回転可能型）の実験条件表生成
- 中心点反復数、実行順ランダム化、乱数シードの設定とCSV出力
- 選択した出力応答の二次応答曲面（表示する2因子以外を固定した等高線）
- 学習R²、Leave-One-Out交差検証R²・RMSE
- 品質上限・下限・範囲を組み合わせた同時規格適合領域
- 多次元グリッド探索によるプロセスウィンドウ体積率と中央寄りの推奨条件
- 任意条件での品質予測

デモデータは画面機能の確認専用であり、実際の材料・金型・成形機を表すものではありません。
