# 射出成形プロセスウィンドウ（応答曲面法）

射出速度・保圧圧力・金型温度と、ヒケ深さ・反り量・光沢度の関係を二次応答曲面でモデル化するStreamlitアプリです。各品質規格を同時に満たすプロセスウィンドウも可視化します。

## 起動

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

ブラウザが開いたら、左側からCSVを読み込みます。CSV未選択時はBox–Behnken計画（中心点1回）の13点デモデータで動作します。画面の「入力テンプレートをダウンロード」から書式例を取得できます。

## CSV列

次の6列が必要です。単位は任意ですが、すべての行で統一してください。

```text
射出速度,保圧圧力,金型温度,ヒケ深さ,反り量,光沢度
```

- 10点以上が必須、15点以上を推奨します。
- 3因子の二次項と2因子交互作用を含む完全二次モデルです。
- 実験範囲外には外挿しません。
- LOOCV R²とRMSEで未知条件への予測性能を確認してください。
- 推奨条件は必ず実機の確認実験で検証してください。

## 解析内容

- Box–Behnken計画／中心複合計画（面中心型・回転可能型）の実験条件表生成
- 中心点反復数、実行順ランダム化、乱数シードの設定とCSV出力
- 各品質指標の二次応答曲面（3因子のうち1因子を固定した等高線）
- 学習R²、Leave-One-Out交差検証R²・RMSE
- 品質上限・下限・範囲を組み合わせた同時規格適合領域
- 3次元グリッド探索によるプロセスウィンドウ体積率と中央寄りの推奨条件
- 任意条件での品質予測

デモデータは画面機能の確認専用であり、実際の材料・金型・成形機を表すものではありません。
